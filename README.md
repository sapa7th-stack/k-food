# K-Food Table

Next.js + TypeScript + Tailwind CSS 기반 2단계 다국어 홈 화면입니다.

## 실행

```sh
npm install
npm run dev
```

http://localhost:3000 에서 확인합니다.

```sh
npm run lint
npm test
npm run audit:data
npm run build
```

대표 음식 4종, 카테고리 8종, 500개 레시피 후보 검색, 김치 전용 페이지, 반응형 레이아웃과 한국어/영어 전환을 포함합니다. 사진 출처와 라이선스는 각 레시피 카드와 홈페이지 하단에 표시합니다.

## 언어 설정

기본 언어는 영어입니다. 헤더의 EN / 한국어 버튼으로 전환하며 선택은 kfood-locale 쿠키에 1년간 보관됩니다. 서버도 쿠키를 읽어 새로고침 시 같은 언어로 렌더링합니다. 번역 문구는 src/lib/i18n.ts에서 관리합니다. 쿠키가 차단되면 현재 화면에서의 전환만 유지됩니다.

## 음식 사진 기준

음식 사진을 화면의 최우선 품질 기준으로 관리합니다. 음식의 실제 형태, 선명한 질감과 자연스러운 색, 카드에서의 구도를 확인한 후 적용합니다. 출처와 사용 라이선스도 함께 갱신합니다.

## 데이터 구성

현재 웹 앱은 배포 및 오프라인 안정성을 위해 `src/data`의 정적 데이터를 읽습니다. Supabase 마이그레이션과 초기 데이터 파일은 `supabase`에 보관되어 있지만, 현재 실행 경로에서는 Supabase를 직접 조회하지 않습니다. 운영 데이터의 단일 기준을 Supabase로 바꾸려면 빌드 시 JSON을 생성하는 동기화 단계를 추가해야 합니다.
