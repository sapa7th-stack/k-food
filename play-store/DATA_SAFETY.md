# Google Play 데이터 보안 작성 기준

현재 앱 코드 기준 점검 결과입니다. 광고, 분석 SDK, 회원가입, 위치정보, 카메라, 마이크, 연락처, 결제 기능은 없습니다.

## Play Console 권장 응답

- 앱이 사용자 데이터를 수집하거나 공유하나요?: 아니요
- 전송 중 데이터 암호화: 사이트 통신은 HTTPS 사용
- 계정 생성: 계정 기능 없음
- 계정 삭제 방법 제공: 해당 없음
- 광고 포함: 아니요
- 위치정보 권한: 아니요
- 인앱 구매: 아니요

## 기기 내 저장

표시 언어 선택을 기억하기 위해 `kfood-locale` 쿠키를 최대 1년간 기기에 저장합니다. 이 값은 한국어 또는 영어 선택만 담으며 개인을 식별하지 않고 외부로 전송하지 않습니다.

제출 전에 새 분석 도구, 광고 SDK, 로그인, 문의 양식 또는 외부 SDK가 추가되었다면 이 문서와 Play Console 데이터 보안 답변을 다시 검토해야 합니다.
